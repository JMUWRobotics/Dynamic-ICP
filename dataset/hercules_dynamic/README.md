# HeRCULES high-dynamic demo

Twenty consecutive River Island / 01_day scans selected by the Dynamic-ICP velocity-filter response. The files are method-ready NPZ scans voxelized at 0.3 m; unused reflectivity, intensity, and scan-line fields were omitted. `ground_truth.tum` contains poses interpolated at the selected scan timestamps. See `metadata.json` for provenance and per-frame statistics.

Run `dynamic-icp-viewer dataset/hercules_dynamic` from the repository root to inspect the method stages. The data remains subject to the terms of the original HeRCULES dataset.
